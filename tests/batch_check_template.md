# 批量检索方法论

改动完成后，两向验证确保无遗漏：

## 反向验证（找残留）

旧痕迹是否还有活口。关键在于**找到变化前后唯一不变的标识**——log 标签、函数名、关键词，用它 grep。

```bash
grep -rn '旧标识' --include='.后缀' . | grep -v 排除目录
```

## 正向验证（验引用）

新产物是否全部接上。定义 1 处、调用 N 处，数数对不对得上。

```bash
grep -rn '新标识' --include='.后缀' .
```

---

改动常常横跨代码和文档两边。查的时候一起查，不要分开：

```bash
# 代码和文档一起搜
grep -rn '标识' --include='*.py' --include='*.md' .
```

思想很简单：**旧的不留，新的不断**。不局限于任何语言或改动类型——改什么就用什么当标识搜两边。
